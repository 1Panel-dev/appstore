## 产品介绍

**MLiev IAM** 是木雷坞开源的身份认证与访问管理平台，提供单点登录、用户管理、角色权限和企业身份目录集成。

## 主要功能

- **统一认证**：支持 OIDC、OAuth2、SAML 和 CAS 应用接入，实现单点登录。
- **身份管理**：集中管理用户、组织和角色，支持菜单、接口权限及数据范围控制。
- **多因素认证**：支持 TOTP、短信、邮箱和恢复码。
- **身份源集成**：支持社交登录，以及飞书、企业微信和钉钉目录同步。
- **内置管理界面**：提供管理控制台、登录授权页面和首次安装向导。

## 首次安装

1. 在 1Panel 中选择 PostgreSQL、MySQL 或 MariaDB 数据库服务，填写数据库信息，并选择 Redis 服务及其密码。
2. 安装后访问 `http://服务器地址:端口/install/`。本应用商店配置的默认对外端口为 `8082`，可在安装时修改；容器内服务监听 `8080`。面板填写的数据库和 Redis 参数会自动预填到向导中。
3. 确认授权协议和连接信息，创建管理员账号并完成安装。管理员密码至少需要 12 个字符，没有预设的管理员密码。
4. 安装完成后服务会自动重启，点击“进入应用”进入 `/admin/` 管理控制台。

数据库和 Redis 表单项仅用于首次安装预填，向导中的修改优先；安装完成后使用保存的配置。后续调整连接信息时，应同步修改 `./config/config.yaml` 和对应服务，并重启应用。

## 数据持久化

- `./config`：保存安装配置、安装状态和 `identity-credentials.key` 凭据密钥。备份或迁移时应将整个目录与数据库一并保存。
- `./logs`：保存应用日志。

通过反向代理使用时，应正确转发 Host 和协议头，确保认证回调地址与实际访问地址一致。
