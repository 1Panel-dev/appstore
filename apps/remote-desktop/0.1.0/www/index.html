远程桌面

下载客户端 → 启用被控 → 用设备 ID 与密码连接。账号登录不是必需。

下载安装包

Mac（Apple Silicon） Mac（Intel） Windows / Linux / 全部版本

产物命名约定： rd-desktop-*-mac-arm64.dmg / rd-desktop-*-mac-x64.dmg / rd-desktop-*-win-x64.exe / rd-desktop-*-linux-x64.AppImage / rd-desktop-*-linux-x64.deb。 Linux 包上传后会出现在 Releases；也可放到本站 /updates/。

三步上手

  1. 安装客户端（Windows 安装一般不需要管理员）。
  2. 若本机要被控：点「启用被控端」——仅此时可能弹出 UAC；然后查看本机 ID / 密码。
  3. 另一台机器填对方 ID 与密码，点连接。

自建信令（本机部署后配置）

默认客户端指向演示服。若此页来自你的服务器，请按下面配置（设置 → 应用 → 高级 / 管理员）：

信令 URL：wss://__PUBLIC_IP__:8443/ws
证书指纹：用 openssl 查看网站证书 SHA-256 后粘贴

若网站反代在 443 且有域名，URL 多为 wss://你的域名/ws。 查询参数也可预填本页：?signaling=wss://…（仅展示，仍需在客户端高级项保存）。
