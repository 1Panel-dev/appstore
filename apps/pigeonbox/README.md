## 产品介绍

**PigeonBox（文件快递柜）**是一个匿名口令分享文本/文件的开源自托管平台：像使用快递柜一样寄出与取回内容。创建分享后生成 6 位取件码，收件人凭取件码在任意浏览器打开即可提取，支持有效期与到期自动清理、密码保护、多用户与权限管理，内置 MCP AI 集成与 P2P 设备直传。

## 主要功能

- **匿名口令分享**：文本/文件一键分享，凭取件口令提取；支持密码保护与过期自动清理。
- **多用户与 API Token**：用户注册/登录/封禁管理；个人访问令牌（pb_sk_ 前缀）让脚本与 CI 直接调用接口。
- **多存储后端**：14 种热切换后端：local / S3 / 阿里 OSS / 腾讯 COS / 百度 BOS / 金山 KS3 / 华为 OBS / WebDAV / FTP / SFTP / GCS / Azure Blob / HDFS / OneDrive。
- **分片上传 + 秒传**：大文件分片上传；服务端流式 SHA-256 计算哈希，同哈希文件秒传直接出码。
- **S3 预签名直传**：大文件由浏览器直传对象存储，后端只签发预签名 URL，不占用应用带宽。
- **MCP AI 集成**：内置 Model Context Protocol server，Claude 等 AI 客户端可直接创建/查询/清理文件分享。
- **P2P 联邦与设备直传**：每台服务器都是对称 P2P 节点，多节点口令跨站可达（文件始终源节点直出）；p2pc 端到端加密设备直传。
- **OIDC 单点登录**：对接任意 OIDC IdP，签发本站 JWT；内容审核、SMTP 通知等治理能力内建。
