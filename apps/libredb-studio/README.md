# LibreDB Studio

LibreDB Studio 是一个自托管的、基于浏览器的数据库 IDE，采用 MIT 许可。在服务器上运行，通过浏览器访问，无需把数据库密码分发到每台电脑。

在同一界面下支持 16 种引擎，包括 PostgreSQL、MySQL、Oracle、SQL Server、SQLite、MongoDB、Redis、ClickHouse、Elasticsearch、Apache Cassandra 和 Apache Trino。免费的 MIT 版内置 SSO（OIDC）、RBAC 和完整的查询审计日志。可选的 AI 助手可以连接本地 Ollama 模型，让结构和数据不出内网。

- 仓库：https://github.com/libredb/libredb-studio
- 官网：https://libredb.org

容器监听 3000 端口。
