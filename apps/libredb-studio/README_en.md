# LibreDB Studio

LibreDB Studio is a self-hosted, browser-based database IDE, licensed under MIT. You run it on your server and reach it from any browser, so you do not have to hand out database passwords to every machine.

It supports 16 engines behind one UI, including PostgreSQL, MySQL, Oracle, SQL Server, SQLite, MongoDB, Redis, ClickHouse, Elasticsearch, Apache Cassandra and Apache Trino. SSO (OIDC), RBAC and full query audit logs are all in the free MIT build. The optional AI assistant can run against a local Ollama model, so schema and data can stay inside your network.

- Repository: https://github.com/libredb/libredb-studio
- Website: https://libredb.org

The container listens on port 3000.
