## 产品介绍

**SGLang** 是一个开源的大语言模型、视觉语言模型与扩散模型推理框架，面向 Agent、大规模服务与 RL rollout 场景优化。

## 主要功能

- **高性能推理**：基于 RadixAttention 的前缀缓存复用，提升多轮对话与长上下文吞吐。
- **结构化输出**：支持 JSON 等结构化输出，适合 Agent 与工具调用场景。
- **多模态支持**：支持视觉语言模型（VLM）与扩散模型。
- **OpenAI 兼容 API**：提供 /v1 兼容接口，可直接接入现有客户端。
- **张量并行**：通过 --tp 使用多张 GPU 提升推理能力。

## 使用说明

1. 宿主机需要 NVIDIA GPU、CUDA 13 兼容驱动，并安装 NVIDIA Container Toolkit；安装时请勾选“GPU 配置”。如驱动仅支持 CUDA 12，可参考官方说明使用 `lmsysorg/sglang:v0.5.19-cu129`（最后一个 CUDA 12 镜像）。
2. 安装后通过 `http://<服务器IP>:<API端口>/v1` 调用 OpenAI 兼容接口，请求头需携带 API Key（可在应用参数中查看）。
3. 模型会从 Hugging Face 下载；国内网络可在参数中启用 ModelScope，或把本地模型放到应用安装目录的 `./data/models/` 下（容器内为 `/models`）。
4. 首次启动需要下载并加载模型，健康检查会等待较长时间。
5. 本应用为单节点部署，不支持 RDMA/集群；集群场景请使用容器编排或 Kubernetes。
6. `CUSTOM_ARGS`（自定义参数）会按空格拆分成多个启动参数，带引号的参数不会保留；复杂参数建议直接修改 compose 文件。

默认参数中的 `Qwen/Qwen3.5-4B` 是 4B 小模型，适合单卡；如需更大模型，请按显存调整 `TP_SIZE` 并替换模型。
