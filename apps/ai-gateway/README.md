## 产品介绍

**1Panel AI 网关** 是面向企业和团队的 AI 统一接入与治理平台，提供模型代理、智能路由、权限控制、内容合规和用量分析等能力，让 AI 应用更安全、稳定、经济地使用不同模型资源。

AI 应用只需配置统一的 Base URL 和 API Key，即可通过标准接口访问公有云 API、本地模型及其他模型服务。

## 主要功能

- **统一接入与模型代理**：集中接入不同供应商和本地模型，通过模型映射与账号池统一调度。
- **席位与权限管理**：按用户组、用户和 API Key 管理模型权限、并发限制与 Token 配额。
- **智能路由**：根据请求内容与预设规则，将任务分发至合适的模型组。
- **负载与并发控制**：结合账号优先级、实时负载和健康状态分配请求，降低单点依赖。
- **内容合规与审查**：提供敏感词、语义审核和调用内容审计能力。
- **用量分析**：统计请求量、Token 消耗、缓存利用率和响应耗时，帮助团队分析成本与排查问题。

## 数据库版本选择

- `1.4.0`：使用 SQLite，适合单机部署，已有 SQLite 实例可沿此版本线升级。
- `1.4.0-postgres`：使用 PostgreSQL，需要 1Panel v2.4.0 及以上版本和 PostgreSQL 18。安装时选择已在 1Panel 中配置的 PostgreSQL 服务，由面板创建并关联应用数据库。
- 两个版本均使用 `1panel/ai-gateway:v1.4.0` 镜像，通过数据库配置区分。应用目录保存配置等持久化数据；PG 版的数据库由所选 PostgreSQL 服务保存，备份请使用 1Panel 的应用备份功能以包含关联数据库。
- SQLite 与 PostgreSQL 版本之间不能直接升级或交叉恢复备份。切换数据库类型需要单独迁移数据。
