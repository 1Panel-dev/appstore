# zPush

自托管 Webhook 事件路由与通知推送系统。接收外部 Webhook（如 Diun、CI、监控告警），经过**字段映射 → 规则匹配 → 模板渲染**的事件处理管线，最终投递到钉钉 / 飞书 / 企业微信 / 邮件 / HTTP 等渠道

## 安装说明

安装时会要求填写以下参数：

- **端口**：Web 管理界面的访问端口，默认 9003
- **加密主密钥**：必须填写，格式 `v1:<base64>`。生成命令：

  ```bash
  openssl rand -base64 32
  ```

  在输出前面加 `v1:` 前缀后填入，例如 `v1:AbCdEf...=`。

  > ⚠️ 该密钥用于加密渠道与数据源的密钥，**丢失后已加密的密钥将无法解密，请务必保存**。修改密钥后重新安装不影响已存储数据，但需使用同一密钥

- **初始管理员用户名/密码**：首次启动创建管理员账号使用（仅首次启动、数据库中尚无管理员时生效）
- **数据库信息**：使用外部 MySQL（推荐通过 1Panel 应用商店安装 MySQL 并在「数据库」中提前创建 zPush 库与用户），安装时选择数据库服务并填写库名 / 用户 / 密码。zPush 首次启动会自动建表迁移，无需手工导入 SQL

## 使用

安装完成后访问 `http://<服务器IP>:<端口>`，使用安装时设置的管理员用户名和初始密码登录

首次使用流程：创建数据源 → 配置字段映射 → 编写规则 → 创建模板 → 配置投递渠道，然后把外部系统的 Webhook 指向 `http://<服务器IP>:<端口>/ingest/<数据源slug>` 即可

详细文档见 [官方 README](https://github.com/z1zhang/zpush)
