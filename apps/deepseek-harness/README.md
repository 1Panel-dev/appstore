## 产品介绍

**DeepSeek Harness（dsh）** 是 DeepSeek 开源的智能体开发环境，提供 Web 对话界面、工作区文件操作、命令执行、工具调用和会话管理能力。

当前版本为开发者预览版。Harness 可以在工作区中执行命令和修改文件，请设置强密码，并避免挂载宿主机根目录、Docker Socket 或其他敏感目录。

## 访问方式

安装后通过以下地址访问：

```text
https://服务器公网IP:安装时设置的HTTPS端口
```

安装时的“访问地址”请填写浏览器实际使用的 IPv4 地址或主机名，例如 `192.168.1.10`，不要包含 `https://`、路径或端口。Caddy 会为该地址生成内部证书，不需要 ACME 邮箱，也不会占用宿主机的 80、443 端口。

由于证书由本地 CA 签发，浏览器首次访问会提示证书不受信任。可以选择继续访问，或者将安装目录下的以下根证书导入客户端系统信任库：

```text
data/caddy/pki/authorities/local/root.crt
```

导入根证书后，使用安装时填写的访问地址即可消除警告。访问地址发生变化时，请在应用参数中修改后重建容器。

## 数据目录

- `data/dsh`：Harness 配置、会话和用户数据
- `data/workspace`：智能体工作区
- `data/caddy`：Caddy 内部 CA 和证书数据

访问地址可以填写内网 IPv4、公网 IPv4 或能够解析到服务器的主机名，但必须与浏览器地址栏中使用的地址一致。
