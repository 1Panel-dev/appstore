# Outline

## Introduction

A fast collaborative knowledge base for teams, supporting Markdown, collections, full-text search, comments, attachments, import/export, API access, and public sharing.

This package targets **quick LAN or overlay-network deployments**: a pre-configured Keycloak service is bundled, so users sign in with a **username and password**. No domain, HTTPS, email, passkey, or manual OIDC client setup is required.

## Features

- Documents, collections, and realtime collaborative editing.
- PostgreSQL full-text search.
- Comments, notifications, permissions, and public sharing.
- Attachments, import/export, and API keys.
- Built-in password authentication with self-service member onboarding.

## Before Installation

You only need services already installed in 1Panel:

- PostgreSQL 14 or later.
- Redis 4 or later.

No domain, certificate, SMTP account, or external identity provider is required.

## Installation Parameters

| Parameter | Default | Description |
| --- | --- | --- |
| Outline HTTP port | `12115` | Knowledge base access port |
| Keycloak HTTP port | `12116` | Sign-in service port |
| PostgreSQL service | pick existing instance | Outline database |
| Redis service | pick existing instance | Cache and queues |
| Outline public URL | `http://server-ip:12115` | Address used by the browser |
| Keycloak admin password | `outline-admin` | Also the initial Outline password; change it |

The database name, database user, and database password are generated by 1Panel.

The Keycloak public URL, OIDC client secret, and redirect URL are derived automatically during installation.

## First Sign-In

1. Open `http://<server-or-overlay-ip>:12115`.
2. The browser redirects to the sign-in page. Enter:
   - Username: `admin`
   - Password: the Keycloak admin password from installation
3. You land directly in Outline. The workspace and administrator account are created automatically.

There is no workspace wizard, no email round-trip, and no confirmation link.

## Interface Language

The sign-in page defaults to Simplified Chinese and Keycloak follows the browser language.

To switch the Keycloak admin console to Chinese:

1. Sign in at `http://<server-or-overlay-ip>:12116` as `admin`.
2. Open the user menu in the top-right corner and choose `Manage account`.
3. On `Account security` → `Signing in`, set the language to Chinese (Simplified).

Both surfaces default to Chinese:

- **User sign-in page** (reached from 12115): controlled by the `outline` realm default locale, Chinese from installation.
- **Admin console** (12116): Keycloak cannot configure the master realm through realm import, so the package starts a one-shot init container that enables Chinese for the master realm. It exits when done and does not affect app status.

If the init container could not complete (for example after you change the admin password), enable it manually:

1. Sign in to the console on 12116.
2. Switch to the `master` realm in the top-left selector.
3. `Realm settings` → `Localization` → enable `Internationalization`.
4. Select Chinese (Simplified) under `Supported locales` and set it as `Default locale`.
5. Refresh the page; the language selector appears on the sign-in page.

## Adding Members

1. Open `http://<server-or-overlay-ip>:12116` for the Keycloak admin console.
2. Sign in as `admin` with the admin password.
3. Switch to the `outline` realm in the top-left selector.
4. Open `Users`, click `Add user`, and fill in:
   - Username
   - Email
   - First name / Last name
   - Enable `Email verified`
5. On the `Credentials` tab, click `Set password`, set a password, and turn off `Temporary`.
6. The new member opens `http://<server-or-overlay-ip>:12115` and signs in.

On first sign-in, Outline automatically adds the account to the same workspace; no extra invitation step is needed.

## Changing Passwords

The initial password is written to Keycloak only on first installation. Change passwords in the Keycloak console afterwards:

- Keycloak console administrator: `Realm settings` → `Users` → `admin` → `Credentials`
- Outline users: switch to the `outline` realm → `Users` → select the user → `Credentials`

Editing the password in the 1Panel form does not overwrite an already initialized Keycloak database.

## Email Notifications

Email is optional. Without SMTP:

- Sign-in still works with username and password.
- There are no email notifications or email invitations; in-app notifications still work.

Fill in the SMTP parameters in 1Panel if email notifications are needed.

## Reverse Proxy and HTTPS

On a LAN or overlay network you can use `http://<ip>:12115` directly without a reverse proxy.

If the service is exposed publicly, create reverse proxy sites in 1Panel and enable HTTPS for **both** Outline and Keycloak:

| Hostname | Proxy target |
| --- | --- |
| Outline hostname | `http://127.0.0.1:12115` |
| Keycloak hostname | `http://127.0.0.1:12116` |

After changing the access address, update the Outline public URL parameter and rebuild the app so the Keycloak redirect URL stays in sync.

Add the following Nginx advanced configuration to the Outline site:

```nginx
proxy_http_version 1.1;
proxy_set_header Upgrade $http_upgrade;
proxy_set_header Connection "upgrade";
proxy_set_header Host $host;
proxy_set_header X-Real-IP $remote_addr;
proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
proxy_set_header X-Forwarded-Proto $scheme;

client_max_body_size 250m;
proxy_read_timeout 600s;
proxy_send_timeout 600s;
```

## File Storage

Local filesystem storage is enabled by default, with attachments under `data/outline`. Upload, document import, and workspace import are limited to 250 MiB and must match the reverse proxy `client_max_body_size`.

## Backups and Upgrades

Before upgrading, back up:

1. The PostgreSQL database.
2. `data/outline`: attachments.
3. `data/keycloak`: Keycloak accounts, passwords, and realm configuration.
4. `data/secrets`: Outline secrets and the OIDC client secret.

Losing `data/keycloak` or `data/secrets` breaks sign-in, so back them up together.

The upgrade script preserves existing secrets, regenerates the Keycloak realm file to match the current parameters, and never removes Docker volumes. Outline runs its own database migrations at container startup.

## Security Recommendations

- HTTP is acceptable for LAN testing; enable HTTPS before exposing the service publicly.
- Port 12116 is the authentication service and must be reachable by browsers, but do not expose it to unauthenticated public networks.
- Do not expose PostgreSQL or Redis to the internet.
- Replace the default administrator password with a strong one.
- Do not use the `latest` image tag.
