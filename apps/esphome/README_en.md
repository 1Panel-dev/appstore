## Introduction

**ESPHome** is an open-source tool for configuring smart home devices and managing their firmware. Use the visual Device Builder or YAML configuration files to build firmware for ESP32, ESP8266, RP2040 and other microcontrollers, and connect them to Home Assistant and other home automation systems.

## Features

- **Device Configuration**: Configure sensors, switches, displays and other components using the visual Device Builder or YAML files.
- **Firmware Management**: Build and install firmware, update devices over the air and view runtime logs.
- **Local Integration**: Connect devices to Home Assistant on your local network without relying on cloud services.
