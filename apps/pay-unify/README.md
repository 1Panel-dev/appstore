## 产品介绍

Pay-Unify 是一款统一支付中台，聚合 **支付宝 / 微信支付 / PayPal** 三个渠道，提供统一下单、查询、关闭、退款接口。

内置管理控制台，可视化配置支付渠道参数与证书，保存即生效无需重启；面向商户提供 OAuth2 Client Credentials 开放 API 与细粒度 scope 授权。

## 主要功能

- **多渠道统一接口**：一套 `pay / query / cancel / close / refund` 覆盖支付宝、微信支付 v3、PayPal
- **渠道热配置**：渠道开关与参数存于数据库，控制台保存即时生效
- **证书全生命周期管理**：控制台上传支付宝 / 微信证书，自动落盘并热加载，无需手填服务器路径
- **可视化管理控制台**：订单、用户、商品、项目、金币积分、会员令牌、审计日志
- **商户开放平台**：`client_id` / `client_secret`、OAuth2 令牌、20 个细粒度 scope、IP 白名单与限流
- **异步回调与自动关单**：支付回调验签、过期订单定时自动关闭
- **安全**：管理员 JWT 会话 + HttpOnly Cookie + CSRF 双重提交、登录失败锁定、操作审计
