## Introduction

**ComfyUI** is a modular AI creation engine that provides fine-grained control over models, parameters, and outputs through a visual node graph.

## Features

- **Visual Workflows**: Build and reuse image, video, audio, 3D, and text workflows with a node graph.
- **Broad Model Support**: Supports a wide range of open models, workflow templates, and custom-node extensions.
- **Local Runtime and API**: Run workflows locally and integrate them into other applications through APIs.
