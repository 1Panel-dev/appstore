## Introduction

**CLIProxyAPI** is an open-source proxy that exposes AI services through OpenAI-, Claude-, and Gemini-compatible endpoints. The management panel lets you configure upstream services and client keys in one place.

## Usage

Set two distinct random keys during installation. Open `/management.html` and enter the management key to configure upstream services. The app downloads its management panel from GitHub.

For OpenAI-compatible clients, use `/v1` as the API base path and provide the API key set during installation. You can change client keys in the management panel after the first startup.
