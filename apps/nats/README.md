## 产品介绍

**NATS** 是一个开源、高性能的云原生消息系统，支持发布/订阅、请求/响应等消息模式。

## 主要功能

- **高性能**：轻量级、低延迟，适合云原生、微服务与边缘场景。
- **多种消息模式**：支持发布/订阅、请求/响应、队列组等核心消息模式。
- **内置监控**：提供 HTTP 监控端点（8222），可查看连接、订阅等运行状态。
- **多语言客户端**：提供 40 多种语言的官方与社区客户端。
- **JetStream 持久化**：默认启用 JetStream，消息流、KV 与对象存储数据持久化到 `./data`。

## 部署说明

本应用为单节点部署，不支持集群；如需集群，请使用 1Panel 的容器编排或 Kubernetes 部署。
