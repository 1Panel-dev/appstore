## 产品介绍

**Silo** 是由 [Pigsty](https://pgsty.com) 社区维护的 MinIO 分支。在 MinIO 官方停止维护其社区版之后，Silo 继续提供高性能、与 Amazon S3 API 兼容的对象存储服务，适合为机器学习、分析与应用程序数据工作负载构建高性能基础架构。

Silo 与 MinIO, Inc. 无关联，也未获得其认可或赞助。

## 主要功能

- **S3 兼容**：完整兼容 Amazon S3 API，现有 S3 工具与应用程序可直接对接，迁移与扩展成本低。
- **高性能**：支持并行读写与低延迟访问，适合需要快速访问海量数据的场景。
- **纠删码冗余**：根据节点与磁盘数量自动确定纠删码配置，单机多盘、多机多盘拓扑均可获得数据冗余。
- **数据安全**：支持 TLS 传输加密、服务端加密（SSE）以及细粒度的访问策略控制。
- **多租户与版本控制**：支持多用户、桶策略、对象版本控制与对象锁定，可在单个实例中为不同组织或用户提供独立空间。
- **持续维护**：由社区持续跟进安全修复与兼容性更新，并公开安全公告台账。
