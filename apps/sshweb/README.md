## 使用说明

> 安装时设置的 **管理密码** 仅在首次初始化时生效，之后以数据目录中的数据库为准，可在面板右上角「修改管理密码」处更改。
> 打开网页后点右上角「📡 加入」生成探针安装命令，在目标服务器执行即可接入监控。

## 产品介绍

**SSHWeb** 是一款开源、轻量的服务器探针监控面板。在任意服务器上执行一条安装命令接入探针，即可在网页端实时查看 CPU、内存、磁盘、网速、负载、在线时长等状态，探针按上报 IP 自动识别归属地并显示国旗；数据支持公开或密码查看、IP 掩码等隐私策略。

在监控之外，SSHWeb 还提供 SSH 网页终端作为辅助管理能力：登记的 SSH 服务器可直接在浏览器中打开真 PTY 终端（vim / htop 等全屏程序原样可用），凭据仅保存在你自己的服务器上。

整个面板以 Minecraft 风格 3D 农场呈现：每台服务器是一只鸡，每个探针是一只带国旗的探针鸡，多人可同时在场景中漫游互动，让服务器监控变得轻松有趣。

## 主要功能

- **探针监控（核心）**：一条命令安装探针 agent（纯 bash + systemd，无二进制依赖），每 5 秒上报 CPU / 内存 / 磁盘 / 上下行网速 / 负载 / 在线时长 / 进程数，网页端 3D 信息卡实时展示，国旗按 IP 自动识别（内置 306 国旗，离线可用）
- **隐私策略**：探针可设为完全公开或密码查看，支持 IP 第三段掩码显示
- **SSH 网页终端（辅助）**：登记 SSH 服务器后在浏览器直接打开真 PTY 终端，支持密码 / 私钥认证，凭据不出本机
- **单容器部署**：无外部数据库和 CDN 依赖，数据持久化在挂载目录中（SQLite 单文件）
- **多人协作场景**：多名访客可同时进入 3D 农场漫游、互动
