## 安装前请注意

此应用使用 Apache 官方镜像，供全新安装。已有 **Kafka (Bitnami)** 的用户请保留旧实例，选择空闲的 TCP 端口，使用新实例自己的数据目录。需要迁移时，请在验证主题、消息和消费组位点后再下线旧实例。

## 产品介绍

**Kafka (Apache)** 按主题存储事件。生产者写入消息，消费者可以按分区顺序读取，并从上次提交的位点继续消费。这个应用在一个容器内运行 KRaft 控制器和 broker，将消息和集群元数据保存在安装目录的 `data/` 下。

## 客户端连接

- **在服务器本机连接**时，默认使用 `127.0.0.1:9092`。如果安装时修改了 TCP 端口，请使用实际端口。
- **从其他主机连接**时，将「客户端访问主机」填为客户端可达的服务器 IP 或域名，只填主机部分，并在面板中开启端口外部访问。客户端使用该主机和安装时设置的 TCP 端口连接。此端口使用明文协议，请仅向可信网络开放。
- **从同一 `1panel-network` 的容器连接**时，使用 `Kafka容器名:19092`。
