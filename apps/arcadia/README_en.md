## Introduction

**Arcadia** is a One-Stop Code Automation & DevOps Platform.

Script writing, scheduled task execution, service hosting, message aggregation, and AI Agent runtime infrastructure—all managed through a single dashboard for the entire workflow.

## Features

- **Scheduled Tasks**: Create, schedule, and manage automation tasks.
- **Multi-language Execution**: Run scripts and programs in multiple language environments.
- **Code and File Management**: Synchronize repositories and manage remote files and personal scripts.
- **Web UI and CLI**: Use both a web control panel and command-line tools.
