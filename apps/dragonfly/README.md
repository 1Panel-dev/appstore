## 产品介绍

**Dragonfly** 是一款兼容 Redis 和 Memcached 协议的内存数据库，适合用作应用缓存、会话存储和实时排行榜。本安装包默认启用 Redis 协议，可通过 `redis-cli` 或现有 Redis 客户端连接。

## 主要特性

- **多核并发处理**让单个实例可以利用多个 CPU 核心并行处理读写请求。
- 支持字符串、哈希、列表、集合和有序集合等**数据结构**。例如，可用哈希保存用户属性，用有序集合按分数维护排行榜。
- **缓存管理**支持为键设置过期时间。启用缓存模式后，内存接近上限时会自动淘汰数据，为新写入腾出空间。
- **快照**会在正常关闭时写入数据目录，下次启动时自动加载。也可以用 `BGSAVE` 在后台生成快照，或设置定时快照。
