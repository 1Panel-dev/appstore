## 产品介绍

**WebStats（Wstats）** 是一套私有化部署的网站统计系统：服务端为原生 PHP + MySQL + Redis（无需 Composer，也不需要 phpredis 扩展），管理端基于 React + Semi Design，前端采集 SDK 零依赖。所有流量数据都留在你自己的服务器上。

## 主要功能

- **核心指标**：PV / UV / 独立 IP / 会话数 / 平均停留时长 / 跳出率，含实时在线人数与今日分时曲线
- **来源分析**：渠道构成与趋势、外链、UTM 五参、广告平台、搜索引擎来路关键词
- **行为下钻**：会话列表与单次访问的完整行为日志、页面下钻、访客旅程、漏斗与转化目标
- **地域与终端**：IPv4 / IPv6 双离线 IP 库解析访客地域，终端环境（浏览器 / 系统 / 设备 / 分辨率）分析
- **多站点多用户**：站点经两步文件验证后锁定，所有者 / 编辑者 / 只读三级权限，操作日志逐条留痕
- **数据出口**：开放 API（PAT 令牌）、CSV 导出、流量异常告警与日报推送

## 使用说明

- 默认端口 `8080`，安装时可修改
- 用安装时填写的**管理员邮箱**与**管理员密码**登录
- 数据库与 Redis 复用 1Panel 应用商店中已安装的 MySQL / Redis
- 接入被统计站点：站点管理 → 添加站点 → 文件验证 → 复制 SDK 安装代码到目标站点 `<head>`
- 若站点前套了反向代理或 CDN：把「访客 IP 取值来源」改为 `X-Forwarded-For` 或 `X-Real-IP`，否则访客 IP 会全部变成代理地址
