## 访问控制台

**默认地址** `http://服务器IP:6333/dashboard`。请将 `服务器IP` 换成实际 IP。如果安装时修改过 HTTP 端口，请将 `6333` 换成对应端口。

在 1Panel 的 **应用商店 → 已安装** 中找到 Qdrant，点击 **参数**。在 **Web 访问地址** 一栏点击 **自定义**，选择 `http`，填入 `服务器IP:6333/dashboard` 并点击 **确认**。之后可通过应用列表中的 **跳转** 打开控制台。

## 产品介绍

**Qdrant** 是一款开源向量数据库，可以为文档、商品或图片的向量建立索引，按相似度查找匹配的记录，适用于语义搜索、推荐和检索增强生成（RAG）。

## 主要功能

- **混合检索**可以在一次查询中结合稠密向量和稀疏向量，同时考虑语义相似度和关键词匹配。
- **元数据过滤**支持按记录附带的 JSON 字段筛选。例如，搜索相似商品时，可以只返回指定价格范围内的有库存商品。
- **内置控制台**支持使用安装时设置的 API 密钥管理集合，应用也可以通过 REST 或 gRPC 接入。
- **集合快照**可备份集合中的向量、索引和元数据。
