## Introduction

Snipe-IT helps IT teams keep track of who has each device, where it is located, and how many seats remain on each software license.

## Features

- Record device checkouts, returns, and maintenance in each asset's history.
- Track software license assignments, accessories, and consumable stock.
- Generate barcode or QR code labels for inventory audits.

## Email notifications

To send checkout notifications or password reset emails, enter your SMTP settings and sender address in `config.env` in the installation directory, then recreate the application container.
