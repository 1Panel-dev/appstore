## Introduction

**wg-easy** combines WireGuard VPN with a web administration interface for managing VPN clients in a browser.

## Features

- **Client management**: Create, edit, delete, enable or disable clients and set expiration dates.
- **Configuration sharing**: Connect clients using QR codes or configuration files, with one-time sharing links.
- **Connection statistics**: View client connection status, transfer statistics and traffic charts.
- **Account security**: Supports two-factor authentication and OIDC login.
- **Multilingual interface**: Supports multiple languages and automatic light and dark themes.
