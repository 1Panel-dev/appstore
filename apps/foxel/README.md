# Foxel

Foxel 是面向个人和团队的开源私有云盘，支持统一管理多种存储后端，并提供 AI 语义搜索。

## 主要功能

- 统一浏览、上传、下载、移动和分享文件。
- 通过适配器接入本地存储、S3、WebDAV、SFTP、FTP、SMB 及多种网盘服务。
- 在浏览器中预览图片、音视频、PDF、Office 文档和代码。
- 提供角色和路径级权限控制、审计日志及带密码或有效期的分享链接。
- 支持 AI 语义搜索、AI 助手、插件和后台任务。
- 通过 WebDAV、S3 API 和临时直链访问文件。

## 安装与初始化

1. 设置网页端口，默认端口为 `8088`。
2. 保留安装表单分别随机生成的身份认证密钥和临时链接签名密钥；如手动设置，请使用两个不同的高强度随机值，并妥善保存。
3. 如使用域名或外部 MCP 客户端，在“公开访问地址”填写完整访问地址，例如 `https://cloud.example.com`。仅通过 IP 访问时可留空；如需外部 MCP 访问，应填写包含端口的实际地址。
4. 启动后通过 1Panel 应用列表打开 Foxel，或访问 `http://服务器IP:网页端口`，按照首次启动向导创建管理员账号。

本应用使用官方镜像 `ghcr.io/drizzletime/foxel:v2.3.4`，支持 `amd64` 和 `arm64`。默认使用 SQLite，无需额外安装数据库。AI 语义搜索需要在 Foxel 中另外配置 Embedding 服务和向量数据库，相关外部服务可能产生费用。

## 数据与升级

- 应用目录中的 `./data` 挂载到容器内 `/app/data`，持久化保存数据库、配置、插件及本地存储文件。
- 配置本地存储适配器时，可使用容器内 `/app/data/mount` 路径，使文件保存在持久化目录中。
- 升级前请备份完整的 `data` 目录，并保留原有两项密钥；升级时沿用数据目录。
- 卸载前请备份需要保留的数据。
